Changelog

Release history

Every NovaFile release, newest first.

NovaFile 1.3.0 Current

EXR thumbnails, a mouse selection box and your own tab names.

  • OpenEXR thumbnails — .exr frames (Nuke / VFX image sequences) now show a real picture instead of a blank icon, on every PC, with nothing extra to install. All standard compressions are supported, including DWAA/DWAB and PIZ, plus tiled and multi-part files.
  • Selection box — press on empty space and drag to select many files with the mouse. In Details / List view you can also start from the empty part of a row. Ctrl+drag adds to the selection; dragging past the edge scrolls the list.
  • Ctrl+click deselects — Ctrl+click on a selected item now really removes it from the selection.
  • Rename tabs — double-click a tab (or right-click → Rename Tab) to give it your own name. Names are remembered between sessions; an empty name goes back to the folder name.
  • Split panes fix — with panes stacked top and bottom, the top pane's Back / Forward / Up buttons now always control the top pane, even while the bottom one is selected.
  • Smaller — the program is about 20% smaller.
  • Installed copies (1.2.0 and later) receive this update automatically inside the app.

NovaFile 1.2.2

Files open on every PC.

  • Opening files fixed — on some PCs a file (for example a Nuke .nk script) showed Cannot open ...: no app registered even though the app was installed. NovaFile now opens files exactly like an Explorer double-click and tries every app Windows has registered for the type.
  • No more dead end — if Windows really has no app for a file type, NovaFile shows the Windows How do you want to open this file? picker instead of an error; your choice is remembered.
  • Installed copies (1.2.0 and later) receive this update automatically inside the app.

NovaFile 1.2.1

One-click updates.

  • Update now really updates — after an update NovaFile reopens by itself, and the update installs fully in the background (no setup window to click or cancel). From now on every new version shows Update available → Update now inside the app.
  • Still on 1.1.0? That version has no update channel built in — install this version once from the download page; every later version then arrives inside the app.

NovaFile 1.2.0

The Explorer release: every Windows command in the right-click menu, safer file operations, automatic updates.

  • Automatic updates — NovaFile now checks for new versions by itself (at start and every few hours), downloads and verifies them in the background and shows Update available → Update now. No more visiting the website for new versions. Coming from 1.1.0? Install 1.2.0 once from this site - every later version arrives inside the app.
  • Full right-click menu — every command Windows offers (WinRAR, 7-Zip, Open with, Send to, Give access to, Scan with Defender, New > every file type, ...) with icons and submenus, in NovaFile's dark style. Type to search any command; the Menu key / Shift+F10 open it from the keyboard.
  • Recycle Bin — Delete moves items to the Recycle Bin (Shift+Delete deletes permanently).
  • Safe copy & paste — paste never overwrites a file (you get name - Copy / name (2)), big copies run in the background with progress (Esc cancels), a folder can never be pasted into itself.
  • Undo — Ctrl+Z takes back the last rename, new item or paste.
  • Drag & drop with Windows — drag files out to Explorer, the desktop or any app, and drop files in.
  • Auto-refresh — folders update by themselves when other programs change them; Refresh keeps your scroll position.
  • Every language — file names in Urdu, Arabic, Chinese, emoji... show, open and can be typed.
  • Easier to learn — a short welcome tour, F1 shows every shortcut on one searchable page, tooltips on the toolbar buttons.
  • Hide the sidebar — Ctrl+S or the panel button gives the files the whole width.
  • Explorer keys — Alt+←/Alt+→/Alt+↑, mouse side buttons, Alt+Enter, Alt+D, F11, Open in Terminal.
  • Lighter and smaller — ~95% less CPU while idle, a ~30% smaller program.
  • Fixes — renaming no longer doubles the extension, an accidental rename is saved by clicking anywhere else, the list scrollbar can be dragged.

NovaFile 1.1.0

Interface scaling.

  • Interface Scaling — a new slider in Settings → Appearance scales text, icons, buttons and spacing from 75% (Extra Small) to 150% (Maximum). The change previews live while you drag and is remembered across restarts; 100% keeps the classic look.

    • Download this version from the download page, or read the guide to get started.

    NovaFile 1.0.0 (Oct 18, 2026)

    Initial release.

    • Folder tabs — multiple tabs per window with reorder, tab menu, and a 20-tab limit; middle-click opens folders in a new tab.
    • Split views — nestable panes (Ctrl+E / Ctrl+W) that each remember their own path and history.
    • Drag-and-drop docking — drag tabs between panes with drop-zone previews.
    • Search — instant ranked filtering of the current folder, Enter scans subfolders with progress and cancel.
    • Navigation — breadcrumb address bar, typed paths, back/forward/up/refresh, sidebar with Recents, Bookmarks, Storage, and Places, plus the Quick Access wheel (C).
    • Views & visuals — five view modes, 15–100% size zoom, shell icons and thumbnails, high-DPI support.
    • Dark & light themes — switchable with Ctrl+T.
    • Rebindable shortcuts — every shortcut editable in Settings with conflict refusal and per-shortcut switches.
    • Session restore — reopen your tabs and panes on launch (Restore Previous Session setting).
    • Built-in updater — Settings → Updates checks a verified release manifest over HTTPS.
    • Installer — per-user Inno Setup installer, no administrator rights required.
