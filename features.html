Features

Everything NovaFile does today

This page lists what is in the current release (1.0.0). Shortcuts shown are the defaults — rebind any of them in Settings.

Ctrl+N · Ctrl+Tab

Folder tabs

Open many folders in one window. Reorder tabs by dragging, close one or close others from the tab menu, and cycle with Ctrl+Tab. Up to 20 tabs per window.

Ctrl+E · Ctrl+W

Split views

Split the window horizontally or vertically to work in two folders at once. Splits nest, each pane keeps its own history, and Ctrl+W closes a pane without losing the rest of the layout.

Drag & drop

Tab docking

Drag a tab over another pane to move it there. Drop-zone highlights show where the tab will land before you release the mouse.

Ctrl+F · Enter

Search that goes deep

Type in the search box to filter the current folder instantly with ranked matches (exact, prefix, word, substring). Press Enter to scan subfolders with progress and cancel.

Address bar

Fast navigation

Breadcrumb segments are individually clickable, typed paths jump straight there, and Back/Forward/Up/Refresh keep history per pane. The sidebar holds Recents, Bookmarks, Storage, and Places.

C

Quick Access wheel

Press C anywhere for a radial wheel of your starred folders, with a live mouse trail. Star folders from the sidebar for one-keystroke access.

F3

Five view modes

Details, List, Tree, Icons, and XL icons — cycle with F3 or the toolbar. Row heights and icon sizes follow a 15–100% zoom with animated resizing.

Thumbnails

Real icons & previews

Shell icons and image thumbnails come from the same source as Explorer, generated on background threads so the window never waits for them. Text stays crisp at any zoom on high-DPI displays.

Ctrl+,

Rebindable shortcuts

The Settings page lists every shortcut with its current key, a record-on-press rebinder, and an on/off switch per shortcut. Command names come from one registry, so the UI never advertises a stale binding.

Ctrl+T

Dark & light themes

Switch between the dark charcoal and light palettes with a keystroke or the settings toggle. The colors match the same system used by the app itself.

Settings · Appearance

Interface scaling

One slider in Settings → Appearance scales the whole interface — text, icons, buttons and spacing — from 75% (Extra Small) to 150% (Maximum). The change previews live while you drag, and the choice is remembered across restarts.

Settings toggle

Session restore

With Restore Previous Session enabled, NovaFile reopens your tabs, panes, and paths exactly as you left them — even if a folder no longer exists, it falls back to your home folder instead of failing.

Settings → Updates

Built-in updater

NovaFile checks a signed release manifest over HTTPS, downloads and verifies the installer in the background, and launches it silently when you choose to update.

Background threads

Stays responsive

Directory scans, icon lookups, and image decodes run on worker threads. The interface thread never runs a shell lookup, so browsing large folders keeps the window smooth.

Ctrl+H

Straightforward controls

Show or hide hidden files with Ctrl+H, sort by any column in Details view, bookmark with Ctrl+B, and toggle the sidebar whenever you want more room.

Crash dialog

Never a silent close

If NovaFile ever hits an internal error it shows a dialog with the fault details instead of simply disappearing — problems are visible and reportable.
