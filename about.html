About

A file manager, rebuilt from scratch

NovaFile is a modern file manager for Windows. It is written from scratch in C directly on the Win32 API — no UI toolkit, no framework, one fast executable.

Pure C on Win32

The platform layer, windowing, and rendering are built directly on Win32 and GDI. There is no Electron, no .NET, and no GUI toolkit in between — just C compiled to a native executable.

One executable, no runtime

NovaFile ships as a single executable that depends only on libraries Windows already provides. Nothing extra to install: download, run, work.

Responsive by design

Directory scans, shell icon lookups, and image decodes all run on background worker threads, so the window keeps responding even in very large folders.

Sharp on every display

The process is DPI aware and every UI element scales through one factor, keeping text and icons crisp at 150–200% display scaling.

Your data stays local

Settings, shortcuts, and session state live in %LOCALAPPDATA%\NovaFile on your machine. The only network activity is the optional update check over HTTPS.

Failures are visible

If NovaFile ever hits an internal fault it raises a dialog with the exception details instead of closing silently — you always know what happened.
