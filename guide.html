Guide to NovaFile

First steps, the working model behind tabs and panes, and every default keyboard shortcut. All shortcuts are rebindable in Settings.

Getting started

  1. Install Run the downloaded NovaFile-Setup.exe — a per-user install with no administrator prompt.
  2. Open a folder Use the sidebar (Recents, Bookmarks, Storage, Places) or type a path in the address bar and press Enter.
  3. Arrange your workspace Open tabs with Ctrl+N, split with Ctrl+E, and drag tabs between panes.

Tabs and split views

  • Tabs — Ctrl+N opens one; Ctrl+Tab / Ctrl+Shift+Tab cycle. Drag to reorder, right-click a tab for shift / duplicate / close-others / close-all.
  • Splitting — Ctrl+E splits the current pane to the right; Ctrl+W closes the focused pane. Splits can nest, and every pane keeps its own path and history.
  • Docking — drag a tab over another pane: the drop zone highlights where it will land, then release to dock it there.
  • Session restore — with Restore Previous Session on (Settings), NovaFile reopens your tabs and panes when it starts.

Searching and navigating

  • Filter as you type — the search box filters the current folder instantly (exact matches first, then prefixes, word starts, and substrings; each step can be toggled in Settings → Search).
  • Go deeper — press Enter in the search box to scan subfolders, with progress and cancel in the status bar.
  • Focus it fast — Ctrl+F or Ctrl+L; Esc clears the query.
  • Breadcrumbs — click any segment of the path to jump there, or press Tab to edit the path directly.
  • Quick Access wheel — press C anywhere for a radial wheel of your starred folders.

Settings and customization

Open Settings with the gear button or Ctrl+,. The panel is generated from NovaFile's command registry, so it always lists every action and switch as the app actually implements it.

  • Rebinding — click a key row and press the new combination. Conflicts are refused with a message; a shortcut can never silently shadow another one.
  • Switches — turn individual features (and their shortcuts) on or off.
  • Storage — settings save immediately to %LOCALAPPDATA%\NovaFile\settings.txt, and the live path is shown under Advanced → Settings file.
  • Updates — Settings → Updates checks for a new release and installs it through the verified background updater.
