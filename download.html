Installation

Up and running in three steps

  1. Download the installer Save NovaFile-Setup-1.1.0.exe to your computer.
  2. Run it Double-click the installer. It performs a per-user install — no UAC or administrator prompt — and can add a Start Menu and desktop shortcut. If Windows shows “Windows protected your PC” on the first run, follow the short guide right below.
  3. Start working Open NovaFile, arrange your tabs and panes, and check Settings → Updates anytime to check for a newer release.

Removing NovaFile later works like any other app: Settings → Apps on Windows, or the entry the installer adds to Programs and Features.

First run

If Windows shows “Windows protected your PC”

Microsoft Defender SmartScreen checks every freshly downloaded app that has no code-signing certificate yet — NovaFile is a new, independently built app, so the very first run of the installer shows this blue prompt. It is a reputation notice, not a virus verdict. This is exactly how to continue:

  1. Click “More info” The dialog expands and shows the file name (NovaFile-Setup-1.1.0.exe) and Publisher: Unknown publisher.
  2. Click “Run anyway” The installer starts immediately — a per-user install with no administrator prompt.
Why the prompt appears, and why running is your choice
SmartScreen blocks apps it does not recognize (too new, unsigned), not apps it detected as malware. The prompt only appears for files downloaded from the internet; the installed NovaFile app itself opens without any prompt.
